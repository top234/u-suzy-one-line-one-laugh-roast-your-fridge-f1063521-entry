# Chewing Gravel

A one-line roast of my fridge for [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521):

> My fridge's ice maker sounds like it's chewing gravel to impress the neighbours.

Why it works: the detail is specific and instantly recognisable — anyone with an ice maker knows that loud gravel-crunching grind. The twist lands in the last few words: the fridge isn't just noisy, it's *performing* for the neighbours, as if the appliance has an ego. It reads cleanly aloud in one breath, and it dodges the worn-out fridge clichés (no light, no cold, no expired food).

## Run

```sh
node main.ts
```

Writes the single roast line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), guarded to 1–200 characters, one line, no leading/trailing whitespace.
